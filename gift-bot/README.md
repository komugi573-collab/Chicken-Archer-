# Chicken Archer Gift Hub

Telegram-бот и Mini App с ежедневными подарками (раз в 24 часа), внутренними монетами, инвентарём, продажей подарков, магазином и промокодами.

## Возможности
- Ежедневный подарок не чаще одного раза за 24 часа на Telegram ID.
- Инвентарь с количеством предметов и продажей за внутренние монеты.
- Магазин косметических наград, каждая покупка — один раз на аккаунт.
- Промокоды с серверной проверкой, лимитом активаций, сроком действия и защитой от повторного использования.
- Telegram Mini App с балансом, ежедневной наградой, инвентарём, магазином и промокодами.
- Фото Chicken Archer отправляется в чат при /start.

## Railway Variables
- DATABASE_URL = ${{Postgres.DATABASE_URL}}
- BOT_TOKEN = токен из BotFather
- APP_URL = публичный HTTPS-домен Railway
- WEBHOOK_SECRET = случайная строка
- SETUP_SECRET = отдельная случайная строка
- ADMIN_IDS = Telegram ID администратора (через запятую)

После добавления переменных открой один раз:
`https://<APP_URL>/admin/setup?key=<SETUP_SECRET>`

## Создание промокода
Администратор пишет боту:
`/promo_create CODE 100 50 72`
Это означает: 100 монет, максимум 50 активаций, срок 72 часа. Последний параметр можно опустить.

Монеты и предметы — виртуальная валюта бота, не деньги; вывода средств и реальных платежей нет.
